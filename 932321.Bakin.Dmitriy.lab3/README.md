## Отчёт по лабораторной работе №3
### Цель работы
Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной вёрстки.
Дополнить макет страницы: Flex-навигацию, Flex-карточки проектов, Grid-галерею, медиа-запросы для планшетов и мобильных, обеспечить отсутствие горизонтальной прокрутки и контрастность не менее 4.5:1.
### Flexbox
Меню сделано через Flex. Пункты стоят в строку. На узком экране переносятся вниз.
Карточки проектов тоже на Flex. Контейнер тянет карточки в ряд. Внутри карточки Flex: постер слева, текст справа.

### Grid
Галерея режиссёров сделана через Grid. На мобильном 1 колонка. На планшете и десктопе 2 колонки. Получается сетка 2×2.

### Медиа-запросы
Два запроса.
600px — карточки по 2, Grid по 2.
900px — карточки по 3.

### Прокрутка
Горизонтальной прокрутки нет. Помогает overflow-x: hidden. И box-sizing: border-box. Ширина карточек считается через calc() с учётом отступов.
