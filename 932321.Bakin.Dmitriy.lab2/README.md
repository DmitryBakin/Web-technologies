#Отчёт по лабораторной работе №2

##Цель работы
Оформить страницу из ЛР №1 с помощью внешнего CSS-файла style.css.
Реализовать: основной стиль во внешнем файле, один элемент с inline-стилями, одно правило во внутреннем блоке <style>, 
CSS-переменные в :root, примеры позиционирования, состояния элементов, контрастность текста не менее 4.5:1.

##Структура файлов
lab1.html — HTML-страница (структура из ЛР №1, добавлены классы и карточки проектов).

style.css — внешний файл со основными стилями.

##Внешний файл стилей
Все основные стили вынесены во внешний файл style.css, который подключён к странице через тег <link>.
Внешний файл задаёт цвета, шрифты, отступы, сетку проектов, состояния элементов и оформление формы.

##Inline-стиль
Один элемент на странице оформлен с помощью inline-стиля — заголовок страницы «Любитель кино и сериалов» в шапке.
Ему задан font-weight: 700 (жирное начертание) прямо в style.

##Внутренний блок <style>
Внутри <head> добавлен блок <style> с одним правилом — оформление боковой панели <aside>:
фиксированная ширина и светлый золотистый фон. Так выполняется требование иметь одно правило во внутреннем блоке.

##CSS-переменные
В :root заданы переменные для цветов и шрифтов:
основной цвет — чёрный;
акцентный цвет — золотой;
