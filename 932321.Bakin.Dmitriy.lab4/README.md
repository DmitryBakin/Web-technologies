# Лабораторная работа №4. Основы JavaScript

## Тема: «Любитель кино и сериалов» (Вариант 6)

Данный проект представляет собой веб-страницу с информацией о кино, к которой подключен интерактивный скрипт на JavaScript. Скрипт анализирует массив с длительностью фильмов и выводит статистику пользователю.

### Задание (Вариант 6)
**Данные:** массив из 5–7 чисел – длительность фильмов в минутах.

**Логика:**
1. **Фильтрация:** оставить только фильмы > 120 минут (полнометражные).
2. **Цикл:** подсчитать количество короткометражек (≤ 40 минут) и их суммарную длительность.
3. **Функции:** реализовать поиск максимума (`findMax`), функцию фильтрации (`filterHighScores`) и подсчёт суммы (`calculateSum`).
4. **Вывод:**
   * Через `alert`: приветствие с именем пользователя и сообщением «Общая длительность просмотра – X минут, из них Y минут – полнометражные фильмы».
   * В `console.log`: количество и суммарная длительность короткометражек.
5. **Дополнительно:** если максимальная длительность ≥ 180 минут, вывести в консоль фразу «Это почти как полноценный театральный спектакль!».

### Структура проекта
* `lab.html` — основная HTML-страница (портфолио любителя кино).
* `style.css` — файл со стилями (темная тема с золотыми акцентами).
* `script.js` — файл с JavaScript-логикой для выполнения задания.
* `README.md` — описание проекта.

### Реализация логики (script.js)
* Массив данных: `const movieDurations = [135, 90, 180, 35, 150, 115, 210];`
* `findMax(arr)` — находит максимальное значение в массиве.
* `filterHighScores(arr)` — возвращает новый массив с фильмами длительностью более 120 минут.
* `calculateSum(arr)` — суммирует все элементы массива.
* Цикл `for` используется для перебора исходного массива и поиска короткометражек (длительность ≤ 40 минут).
* Условный оператор `if` проверяет максимальную длительность для вывода дополнительного сообщения в консоль.
