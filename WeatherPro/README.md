# WeatherPro

WeatherPro — веб-приложение для просмотра демонстрационной погоды в пяти городах. Пользователь может выбрать город и посмотреть температуру и погодные условия.

Важно: приложение использует заранее заданные данные. Это учебный Mock API, а не настоящий прогноз погоды.

## Возможности

- Просмотр погоды в Москве, Лондоне, Париже, Токио и Берлине.
- Переключение температуры между градусами Цельсия и Фаренгейта.
- Получение погодных данных через API.
- Главная страница и страница с информацией о продукте.
- Поддержка PWA и кеширование статических файлов для офлайн-доступа.

## Используемые технологии

- Node.js — среда выполнения JavaScript.
- Express — создание сервера и обработка запросов.
- HTML — структура страниц.
- CSS — оформление сайта.
- JavaScript — работа интерфейса и получение данных.
- PWA — возможность установки веб-приложения на устройство.

## Установка и запуск

Для запуска проекта необходимо установить Node.js.

1. Откройте папку проекта в терминале.
2. Установите зависимости:

```bash
npm install
```

3. Запустите сервер:

```bash
npm start
```

4. Откройте приложение в браузере:

http://localhost:3000

## Маршруты сервера

| Метод | Маршрут | Назначение |
|---|---|---|
| GET | `/` | Главная страница |
| GET | `/about` | Страница с информацией о продукте |
| GET | `/api/weather/:city` | Получение погоды по названию города |

## Пример запроса

Получение погоды в Москве в градусах Цельсия:

```text
/api/weather/Moscow?units=metric
```

Пример ответа сервера:

```json
{
  "city": "Moscow",
  "temp": 23,
  "units": "C",
  "condition": "clear"
}
```

Для получения температуры в градусах Фаренгейта используйте параметр `units=imperial`.

Если город отсутствует в списке, сервер возвращает статус `404` и сообщение:

```json
{
  "error": "City not found"
}
```

## Описание работы

Сервер на Node.js и Express принимает запросы от пользователя. По названию города он находит соответствующие демонстрационные данные и возвращает их в формате JSON. Файл `script.js` получает ответ сервера и показывает информацию на странице.

Service Worker кеширует статические файлы приложения. Поэтому ранее загруженные страницы и ресурсы могут быть доступны без подключения к интернету. Запросы к API не кешируются.

## Назначение проекта

WeatherPro разработан в учебных целях для демонстрации работы Node.js, Express, HTTP-маршрутов, query-параметров, JSON и технологии PWA.
